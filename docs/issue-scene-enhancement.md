# Issue: 增强虚拟场景视觉质量

## 目标

在保持确定性和可重现性的前提下，提升虚拟场景的视觉真实度，为更丰富的测试案例提供基础。

## 背景

当前系统支持两个主要地景：
- ✅ **Hannover**：已实现，基于 OSM 数据 + SRTM DEM
- ⏸️ **Manhattan**：受制于高楼建模问题尚未实现

场景视觉效果基础但功能完整：
- OSM 建筑挤出（简单几何）
- 卡片植被（远景贴图 + 近景卡片）
- 程序化天空（shader）
- 基础光照（太阳方向）

**改进方向**：参考开源 Godot 资源的优秀实践，提升视觉真实度。

## 约束条件

**必须遵守的原则**：
1. ✅ 所有效果通过 shader + Python 参数实现
2. ✅ 不使用需要运行时 GDScript 的插件
3. ✅ 保持场景配置的 JSON 可编辑性
4. ✅ 不破坏确定性和可重现性
5. ✅ 明确素材来源和许可证

**可用资源**：
- Godot Asset Library
- GitHub 开源 Godot 项目
- CC0/MIT 许可的 3D 资源
- 自行开发的 shader 和材质

## 改进方向（不包含具体需求）

以下是潜在的改进方向，具体实施需进一步评估优先级和工作量。

### 1. 天空与大气系统

**当前状态**：程序化天空 shader，颜色简单过渡

**改进方向**：
- 更真实的大气散射（参考 Realistic Environments 的天空 shader）
- 可配置的云层（体积云或程序化云纹理）
- 昼夜循环（太阳/月亮位置、颜色温度）
- 星空（夜间）

**配置示例**：
```json
"sky_system": {
  "time_of_day": 14.5,
  "cloud_coverage": 0.3,
  "atmosphere_density": 1.0
}
```

---

### 2. 天气效果

**当前状态**：无

**改进方向**：
- 雾效果（指数雾、高度雾）
- 雨效果（屏幕雨滴 shader，不是粒子）
- 云阴影（动态投影）
- 光束（体积光 shader）

**配置示例**：
```json
"weather": {
  "type": "fog",
  "density": 0.5,
  "color": [0.8, 0.85, 0.9]
}
```

---

### 3. 建筑材质与细节

**当前状态**：OSM 建筑简单挤出，统一材质

**改进方向**：
- PBR 材质（金属度、粗糙度）
- 细节纹理（砖墙、玻璃、混凝土）
- 窗户反射（环境贴图）
- 屋顶类型（平顶、斜顶、圆顶）
- LOD 优化（远景简化）

**数据源**：
- OSM building:material 标签
- building:roof:shape 标签
- building:levels 精确高度

---

### 4. 植被系统优化

**当前状态**：卡片植被 + 风摆 shader

**改进方向**：
- 更多植被变体（不同树种、灌木）
- 改进 LOD（近景卡片、远景 billboard）
- 更真实的风摆（多层级：主干/枝叶）
- 季节变化（叶片颜色）
- 植被分布策略（基于地形坡度、水源距离）

**配置示例**：
```json
"vegetation": {
  "density": 0.8,
  "wind_strength": 2.5,
  "season": "summer"
}
```

---

### 5. 地形细节

**当前状态**：高度网格 + 单色纹理

**改进方向**：
- Triplanar 贴图（避免 UV 拉伸）
- 多层材质混合（草地、泥土、岩石）
- 细节法线贴图
- 地形装饰（石头、草丛）
- 道路纹理（基于 OSM highway 标签）

---

### 6. Manhattan 高楼建模

**当前问题**：简单挤出无法表现摩天大楼的复杂外形

**改进方向**：
- 分段挤出（底层/主体/顶层不同宽度）
- 玻璃幕墙材质
- 夜间窗户灯光（程序化点光源）
- 标志性建筑的定制模型（如帝国大厦）

**数据源**：
- OSM building:part 标签（分层建筑）
- building:min_level / building:max_level
- 外部 3D 模型（CC0 授权）

---

### 7. 光照与阴影

**当前状态**：定向光（太阳）+ 基础阴影

**改进方向**：
- 软阴影（PCSS）
- 环境光遮蔽（SSAO）
- 全局光照（烘焙或实时 GI）
- 反射探针（建筑窗户反射）
- 天光（天空盒贡献）

---

### 8. 相机与曝光

**当前状态**：固定曝光

**改进方向**：
- 自动曝光（基于场景亮度）
- 色调映射（HDR → LDR）
- 色差（镜头效果）
- 景深（可选，不影响目标识别）

---

### 9. 测试案例丰富度

**当前状态**：少量固定场景

**改进方向**：
- 不同时间段（黎明、正午、黄昏、夜间）
- 不同天气（晴天、多云、雾天、雨天）
- 不同季节（植被颜色）
- 不同地形（平原、丘陵、山地）
- 不同密度（城镇、郊区、乡村）

**目的**：
- 测试算法在多样场景下的鲁棒性
- 评估不同条件对探测性能的影响
